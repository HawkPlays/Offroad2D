# Offroad2D — architecture index
Static ES-module browser game (no build, no npm). Serve the folder over HTTP (`python3 tools/serve.py` = no-cache, avoids stale modules on phones; planck vendored in `engine/vendor/planck.mjs`, no internet needed), open `index.html` (`?level=<id>&vehicle=<id>&cam=2d|2.5d&atmo=day|dusk|overcast|night` preselects; atmo else random per `start()`).
Units: m, kg, s, rad; +x forward, +y up, +z = truck right (near side in 2.5D). New level / truck = one JSON + a `content.json` entry mirrored in `engine/manifest.js` `FALLBACK_MANIFEST` (static hosts: no dir listing; `mergeManifest`, test-checked). `index.html` is glue only (`color-scheme: only dark` meta + `:root` stop Chrome/Brave dark modes; Samsung ignores it → start-screen metal text/tags/START painted on canvas, hud.js `PAINT`): menu → fetch JSON → HUD `state` → `car.controls` → `phys.step(dt)` → `renderer.draw()` + `hud.update()` + `audio.update()`; `phys.events` → toasts; finish = `x > level.finish.x` (+ `audio.jingle('finish')`; FINISH panel NEXT › = same truck, next manifest level, greyed on the last; key N); top-centre `hud.setRunInfo('Level · STAGE n · Truck')`; RESET tap = `recoverRun()` → `recover(0.9, heal)` (vehicle `RECOVER`: footprint within `margin` 0.35 m of a log / boulder / wall shelf it overlaps in z → backs off along the trail in 0.25 m steps ≤ 8 m (never onto a bridge span / before spawn) to clear ground at `_surfaceTop` + 0.35 m, else lifts in place; `grace` 1.5 s after any recover = no impact damage / crash stall: lifting onto the boulder it hung on used to slam it back down, +0.16 body per tap; test 'recover on a boulder'): recovery unlimited, FIELD REPAIR (`REPAIR` heal 0.6 of body/shock/axle-stress, snapped axles stay) only when charged: ready at run start, recharges `REPAIR.cool` 120 s of run time after use, not spent with nothing to fix (RESET border amber + fill bar while charging, `hud.setRepair(f)`), hold = restart (full repair); frame loop: draws ≤ 60 fps (`frameCap || 60`, −6 ms slack: 120 Hz = every 2nd vsync; no render interpolation, so faster only judders) + vsync snap (dt within ±2.5 ms·n of n/60 → exactly n steps, accumulator clamped: no 0/2-step hitches at speed); best time per level in localStorage `o2d.bests` `{levelId: {time, vehicle, score}}` (best score kept separately) → menu cards (+ a vertical 3-star strip at each level card's right edge, `.card-stars`: `starsOf(best score)`, old time-only bests = 1, unplayed = empty outlines) + FINISH (NEW BEST!; par = level `par` s); camera mode in `o2d.cam`, HUD sizes in `o2d.ui`.
## Drivetrain / fuel (`vehicle.js`): runs start 2WD, lockers open, `range` H (`hud.resetControls()` in `start()` + `car.resetControls()` in ctor/`reset()`). `controls.range` H|L+|L|L- (legacy `low:true` = L; commits only at chassis |v| ≤ `SHIFT_SPEED` 0.3 (any direction), else `pendingRange`); the HUD drives `controls.gate` instead (H-gate `GATES` H L+ L L- N R, overrides range/reverse when set: `_shiftGate` — a slot with another range or direction waits for a stop as `pendingRange` (= the slot; HUD gate pulses red), into N is instant (and N back to the same slot); N = `neutral`: no drive, no engine braking, free revs; R = reverse in L+ gearing; state `gate`, `neutral`, gear 'N'; test 'H-gate'): `RANGE_CFG` × lowSpeed governor (L+ ~15, L ~10, L- ~5 km/h); in Low the pedal is an rpm request: shaft ceiling = idle + (redline − idle)·gas^`LOW_PEDAL` 0.6 (half gas ≈ ⅔ revs / speed; before, any gas ran a light Low (Buggy / Fango: redline before the governor) onto the limiter = 'floored' sound at half gas) / ×lowMult torque (1, 1.25, 1.6) / ×lowBrake. Fuel `hc.fuel` 1→0 (`DEFAULT_FUEL`, per truck `fuel {}`): burn/s = (idle + rev·(rpm/redline)²·thr + spin·min(slip/spinRef,1)·thr) / `fuel.tank` (Buggy 0.6, Truggy 0.75, Fango 0.7: evens out per-truck burn); every level starts full (no level `tank`, no jerry cans in content; `cans` support kept in code); spin term ×0.35 while the winch reels in (the drum pulls, tyres only paddle); 0 → `dry` (power 0, `out-of-fuel`); recover keeps it, reset refills. Tests: careful crawl uses 10–32 % per level, full-gas mashing ≥ 2× per metre.
## Hardcore rules (always on, `vehicle.js`; tune per truck via optional `hardcore {}` = keys of `DEFAULT_HARDCORE`)
- Bind: locked diff (F-Lock needs 4WD) on gripping rock (`bindMu`) at high throttle/speed builds axle stress (×`lockerFastGain` > 25 km/h) → 1 snaps the shaft (`axle-snap`). 4WD centre bind heats the transfer case → 2WD until cool. Redline >70 % gas heats the engine → limp (low ranges ×`engineLowGain` 0.25: crawling at the governor ~90 s floored; overheat steam rises off the bonnet). Engine OFF on spawn/`reset()` (`hc.off`); key = `controls.ignition` counter change / `ignition()` → crank `crankTime` 0.9 s → run (`start`/`restart`; dry → `no-start`), running → `shutdown`; hard starts are MANUAL: bad = max(body, 0.8·engine heat, hot) ≥ 0.15 → the first key turn of a start attempt rolls `hc.startFails` 1..`crankFails` 2 failing turns (≤ 3 key turns at 100 % damage) (each: starter crankTime + `crankFailTime` 0.75 s, one `crank-cough` (audio short misfire + starter dip), then `no-start` {cause 'stumble'}, no toast: players figure it out); reset to null when it catches; any failed turn sets `hc.noStart` (state `hardcore.noStart`) → HUD KEY red (`.fail` pulse) until the next turn; overheated → a catching turn may still not fire (chance ≤ `hotNoStart`, `no-start` {cause 'hot'}); deterministic per key turn (`_crankN`); `startEngine()` = instant (tests/bots). Lug meter `hc.lug` → `stall` {cause}: Low back-driven > `stallBack` (`lug`), Low brake+gas > 50 % (`brake`; Low out-pulls brakes), 4H transHot floored in a bog (`trans`), dry (`fuel`); GAS never restarts, only the key.
- Torque converter (4H): tread < `bogSpeed` under >25 % gas → bog: rpm = `tcStallRpm`, wheel torque ≤ grade-holding torque of `bogAngle`° (×(1+`tcRollback`) rolling back), k² blend to full 4H at `lockSpeed`; bog heats `transTemp` (×`transSteepGain` > `transSteepDeg`), at 1 4H drive = 0 until < `transRecover`. 4L: torque `lowMult`×4H, top speed `lowSpeed`×4H, lift braking ×`lowBrake`. C01 3.5× / best lowBrake, Bogger 3.0× / fastest trans, Buggy 2.2× / 67 km/h 4H, 04 Truggy 2.8× (1.35 t; tuned only via its JSON).
- Brake dive (`DIVE`, per truck `dive {}`, `_brakeDive` in `_preStep`): H range, brake > 5 %, ≥ 3 tyres down: extra nose-down chassis torque = `gain` 0.75 × mass × low-passed braking decel (≤ `max` 9) × COM height, × smoothstep(`v0` 2 → `v1` 11 m/s), eased; tyre load transfer alone dived ~3° from any speed (r14: H stops felt light); now ~3° at 15 km/h → 5–6° from top speed (Buggy 8.8°), stopping distance unchanged; acceleration squat = drive reaction only (kept small).
- Damage: closing speed `rec.vn` — chassis > `bodyHit`, wheel across axis > `wheelHit` / along > `dropHit`, roof landing; a CRASH stalls a running engine (stall {cause 'impact'}, damage event `stalled` → toast '· ENGINE STALLED'): chassis slam ≥ `crashBody` 3.6 m/s or a tyre head-on into a near-vertical face (contact normal |n·chassis up| < 0.5) ≥ `crashWheel` 3.8 m/s; ramps, lips, landings never (test 'crash stall + reverse'; rollover fixtures set both to Infinity). Reverse gear: top speed ×`reverseSpeed` 0.5 of the range, ≤ `reverseMax` 3 m/s tread (~11 km/h H, 7–10 L+). Body dmg cuts power, misfires (> `misfireFrom`); shock dmg softens/sags the corner, loses ≤ `shockDampingLoss` 0.55 damping (0.9 made worn trucks porpoise/shake), slow smooth `shockFlutter` 0.12, bottoms early. HUD DMG bar = permanent damage only (body, worst shock, snapped axle; axle STRESS hidden). RESET tap `recover()` keeps damage (and z); hold `reset()` repairs.
## Lateral trail / steering (2.5D; `trail.js` `TRAIL`, `vehicle.js` `DEFAULT_STEER`, per truck `steer {}`, `track?`)
- Kinematic layer over planck x-y: `controls.steer` −1..1 → front angle (≤ `maxSteer`, `rack`) → bicycle yaw (±`maxYaw` 20°; yaw rate lags the bicycle rate by `yawLag` 0.15 s (`yawRate`); the heading turns about the REAR axle (`_rearLx`: z += −xr·Δsin yaw, rear tyres track inside, never swing out into walls/boulders); held by the lip/a wall: z holds, the heading may not creep deeper (`zTry` test), nose eases ≤ min(`berm`·|vx|, `bermMax` 0.5) rad/s in graded steps (`_easeOut` ¼/½/1), and an eased/held heading zeroes `yawRate` (a carried easing step = the per-frame yaw flip-flop jitter against boulders, r7); released = wheels ease back (`caster` 3.5 /s exp, ≤ `release`·`rack` rad/s) toward a gentle counter-steer `center` 0.8·yaw, only while rolling (∝ speed, full at 2 m/s); parked + released = wheels keep their angle), z' = vx·tan yaw, no z clamp: edge LIP (`TRAIL.lipZ` 2.65 crest, `lipW` 0.2 (outer foot = `rim`: the lip sits at the real edge; flat path to `edge` 1.9, berm `bermW` 0.6), `lipH` 0.14 cosine ridge in `laneOffset` via `lipAt`; physics lanes add `lipUnder` = highest lip under the whole tread (speed bump: a tyre whose edge reaches it rides up, never sinks through it; off while tipping, `lane.foot`); renderer stone kerb on the crest strips): a tyre's OUTER EDGE can't cross the crest outward (`_lipCross` holds z, then yaw, nose eases straight) unless ≥ 90 % lock is held into that edge for `lipTime` 1 s while rolling (`_lipNear`, `_force`) or it hits at lateral speed > `lipPop` → tyres past `TRAIL.rim` 2.85 (+`dropW`) lose their lane (`edgeDrop` −`dropH` 8 m, physics lanes only), one side over (or a diagonal hang: COM ≥ 12 cm outside the grounded tyres' support polygon, `_tipSide`: on 3 tyres it stays up) = tip-over roll about the other side (`tipH`, from rest, centre `drift`s out); past `FALL.commit`·atan(halfTrack/tipH) `_startFall`: every contact released, forward speed ×`vxKeep`, pitch spin ×`spinKeep` then the nose pitches down toward `noseDown` 0.95 rad (≤ `noseRate`), z eases out past rim + halfTrack (`zOut` m/s: never drops through the trail; far side = behind the cliff; headlights off whenever falling or |roll| > 0.15), roll eases to `rollMax` 0.8 rad (far side `rollMaxFar` 0.55) (heavy, near-straight drop; renderer `_truckFrame` maps the extrusion vector through the roll so the body never collapses flat), small drift (`FALL.vz` 0.35), planck gravity drops it (no floor), FALL_DEPTH 1.2 m under `groundAt(x)` = `fell-off` event (glue: camera follows, panel after 1.6 s, `audio.jingle('fail')`); `_zBlocked` walls a hanging tyre from steering back only once it hangs > max(wallStep, 1.3·R) below the edge (a drooped tyre on 3-wheel support climbs back); `reset()`/`recover()` → `_edgeClear` (recover off the edge = back on the trail at `groundAt`). Wheel (lx, lz = ±halfTrack) sits at its rotated (x, z): joint anchors slide lx(cos−1) − lz·sin along chassis x (left side leads turning right → angled log/ledge hits); wheel z picks surfaces + its lane.
- Each wheel collides only with its own lane collider (`addLane`, CAT.LANE<<k, 11 lane bits; shared rigid ground = CAT.GROUND for chassis/logs); the chassis also rides a BELLY lane (`vehicle.belly`, `lane.belly` = half-width ~0.8·body, `win` = half-length + 0.6, yawed footprint): highest `laneOffset` across its width (zone steps / shelves / berms, no ruts / drop) → it high-centres on blocks instead of sinking through them: vertices = ground + `laneOffset` (berms past `edge` + zone `dy`) − rut under the tyre footprint, refreshed ±`win` around the wheel every step. Zones `side` L/R = z<0 / z≥0, `z0/z1`; berm = own surface.
- Side walls (forced steering): partial-width logs/boulders (`z0/z1` on a log → `zs`; physics `_zMiss` disables contacts with tyres (tire.z ± w/2), the chassis (`_zs` = z ± halfTrack) or logs whose z span misses; lenient heading test too: a tyre's span at the contact x along its heading `tire.h` (yaw + steer; z + dx·tan h) and the yawed chassis' span `zsAt(x)` (`_chassisZ`: z + xl·sin yaw ± halfTrack·cos yaw) — a miss by either = no contact (turned away from a boulder = clear, turned in = slides along); rounded boulder ends: a tyre (chassis) whose z span reaches < `LOG.glance` 0.16 (`glanceBody` 0.15) into a rock log's span gets no contact; the tyre sets `tire.glance` → vehicle nudges z out (≤ (0.3 + 1.5|vx|) m/s) = brushes past the tapered lump end; `_zBlocked` on rock never lets steering deepen an overlap (wood: only new entry); lane zones (shelves/steps) likewise sample `laneOffset(…, zq)` along the footprint (`lane.h/r`), least of centre/footprint; `zLogs`); steep flank of a partial ROCK log caps tyre mu at `LOG.faceMu` (|ny| < `faceNy`: no wheelie up it). `vehicle._zBlocked(z, yaw)`: a tyre/chassis entering a partial log it already overlaps in x-y, or a lateral dy rise > `steer.wallStep` 0.25, holds z (then yaw) → slides along. Level boulders: r 0.8–0.88, `embed` 0.1 (tyres meet them at/below the equator → unbashable), z 0.75..2.5 / −2.5..−0.75 (renderer: rounded low-poly rock LUMPS `_lumpMesh`/`_rockLump` (lit facets, silhouette outline, every vertex seated on `_surfY`: never floats / shows under the surface), big lump at the trail-side end + smaller toward the edge, clamped inside the lip; full-width low rock ridges = irregular fractured BLOCKS (r15: widths 0.55–1.45× mean, thin gaps, `_lumpMesh(…, box)` superellipse flat-top meshes, top ≤ l.y + r); flattened-into-ground faces not drawn, contact faces 1–2 shades darker, no outline along ground-contact edges (was the 'chain'); one depth item per lump, a pass draws the front faces whose centroid z is in its range), alternate sides ≥ 15 m apart. Rock FORMATION (`formation: true` boulder + `climb: true` zone): ~65 % of the width a rock block (zone dy 0.38, x 3.4 m) you crawl over, the rest the boulder (bots: climb zones are not walls). Bridges: rope rails at `BRIDGE.rail` 1.85 are tyre walls (`_zBlocked`), entry/exit posts are partial-width (zs) ground fixtures.
## Soft terrain (`physics.js` `RUT`) + log tether (`LOG`)
- Surface `dig` (`/mud|bog/` 1, `/clay/` 0.6) → per-run rut grid `d[i·nz + lane]` (TRAIL.nz lanes, soft flats resampled at `TRAIL.res`); slip > `RUT.slip` digs the lanes under that tyre (× its lane surface dig, ≤ `maxStep`, walls ≤ `wall`, ≤ `maxDepth` 0.35, fades at grade `bank`). Logs/boulders settle, then bed on a gravity-compensated spring-damper (`hz`/`zeta`, `vhz`, `twist`/`creep`; stiffer hz/vhz launched a truck off a log in the determinism course: motion trimmed via zeta 0.85 + twist 0.25 only); ROCK logs (boulders, rock ridges) are frozen `setStatic()` at their bed pose once sunk (`t.frozen`: stone doesn't rock); terrain-resting ones sink `embed`×diameter, drop ground collision; never roll away (`free: true` = loose prop).
